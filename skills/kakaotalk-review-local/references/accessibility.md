# 접근성 준비

첫 실행에서는 설정과 실제 텍스트 노출을 함께 점검한다. 이 스킬을 설치했다는 사실만으로 OS 설정이 변경되지는 않는다.

## macOS

1. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 **Computer Use가 권한을 요청한 구성요소**를 확인한다. OpenAI 안내에는 Codex Computer Use로 표시된다. 설치 환경에서 이름이 다르면 실제 권한 요청을 확인한다.
2. 같은 개인정보 보호 및 보안에서 화면 기록(버전에 따라 화면 및 시스템 오디오 기록)을 확인한다. 권한 적용 후 재실행을 요구하면 해당 안내를 따른다. OS 권한 변경은 도구의 확인 정책을 따른다.
3. 시스템 설정 → 손쉬운 사용 → VoiceOver는 화면 낭독 기능이다. AI 제어 권한과 구분하고, AI 조작만을 위해 켜도록 요구하지 않는다. 사용자가 이용 중인 보조 기능은 존중한다.
4. 카카오톡 설정에 시각장애인·스크린리더·접근성 지원 옵션이 실제로 있는지 확인한다. 지원하면 기본 준비에 포함하고, 활성화 전후 발신자·본문·날짜·시간이 읽히는지 확인한다. 존재하지 않는 Mac 메뉴 경로를 안내하지 않는다.
5. 화면 권한이 있어도 앱이 모든 내용을 접근성 트리에 노출한다는 보장은 없다. 읽히지 않는 부분은 화면으로 보완하거나 미확인으로 표시한다.

## Windows

제공되는 native Computer Use 설정을 따르고 대상 카카오톡 창을 현재 데스크톱에 표시한다. 카카오톡 내부 접근성·시각장애인 지원 옵션이 있으면 기본 준비에 포함한다. Narrator 실행 여부와 AI의 UI 접근 가능 여부를 동일시하지 않는다. Mac 설정 경로를 Windows에 적용하지 않는다.
