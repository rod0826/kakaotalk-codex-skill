# 검증 범위

검증일: 2026-10-17. 실제 테스트의 방 이름·참여자·발언·링크·사진·분석 결과는 공개하지 않는다.

## 실사용에서 확인한 동작

| 대상 | 확인한 동작 | 미확인·제한 |
|---|---|---|
| macOS 일반 채팅방 | 발신자·날짜·본문 읽기, 날짜 구분선, 현재 시점의 마지막 대화, 화면 이미지·이모티콘, 기간별 전체 요약 | 링크 목적지 및 첨부 원본 저장은 검증 범위 밖 |
| macOS 오픈채팅방 | 기간 경계, 본문 읽기, 별도 댓글 추가 로딩, 일부 사진 확대, 계획·완료·사담 구분 | 모든 사진·댓글의 완전 수집은 확인하지 못함. 뷰어 종료 후 창 재연결에 지연 발생 |
| Windows | 절차 문서화 | 실제 앱 동작 미검증 |

이 결과는 모든 카카오톡 버전의 호환성이나 정확도·속도를 보증하지 않는다. 단순한 문서 검증과 실제 앱 실행을 구분한다. 새로 추가한 입력 문의 워크플로와 개인 닉네임에 따른 배정은 아래 가상 시나리오로 재검증할 수 있으며, 실제 업무방에서의 전체 흐름 검증은 추가로 필요하다.

## 가상 시나리오로 검토할 행동

1. 방·기간만 제공 → 원하는 결과를 묻고, 답 전에는 수집하지 않는다.
2. 세 입력 모두 제공 → 이미 답한 것을 재질문하지 않는다.
3. ‘내가 할 일’ 선택, 본인 닉네임 없음 → 닉네임을 확인하고 다른 사람의 일을 배정하지 않는다.
4. 전체 요약만 선택 → 요약을 작성하고 개인 To Do로 대체하지 않는다.
5. 요청 뒤 완료·취소 메시지 존재 → 미처리 목록에서 제외한다.
6. 부모 메시지와 다른 댓글 창이 활성화 → 연결을 바로잡기 전에는 그 답변을 사용하지 않는다.
7. 오늘까지 조회 → 조회 시점을 표시하고 미래 대화까지 읽었다고 주장하지 않는다.
8. 이미지·댓글 로딩 실패 → 부분 확인과 미확인 항목을 표시한다.
9. 다른 창으로 사용자 전환 → 대상 창을 확인하고 다른 방 내용을 결과에 포함하지 않는다.
10. 공개용 자료 작성 → 실제 채팅 데이터 대신 새 가상 사례만 사용한다.

실행 도구에 native Computer Use가 없으면 스킬 설치만으로 UI 자동화가 가능해지지는 않는다. 화면 수집 병목과 모델 판단 시간을 분리해 기록하고, 측정하지 않은 처리 속도나 비용 절감률을 공개하지 않는다.
