# 카카오톡 대화 리뷰 · Codex Skill

일반 채팅방과 오픈채팅방을 Codex의 Computer Use로 읽고, 원하는 형태로 정리하는 한국어 스킬입니다.

**채팅방 → 조회 기간 → 조회 후 할 일**을 확인한 뒤 실행합니다. 별도 로컬 분류 모델이나 카카오톡 비공개 API가 필요하지 않습니다.

## 사용 흐름

```text
사용자: 카카오톡 대화 정리해줘.

Codex: 어떤 채팅방을 조회할까요? 일반 채팅방인지 오픈채팅방인지도 알려주세요.
사용자: 일반 채팅방 ‘새봄 프로젝트’.

Codex: 조회할 기간을 알려주세요.
사용자: 2026년 9월 7일부터 8일까지.

Codex: 조회 후 무엇을 정리할까요?
       전체 요약 / 내가 할 일 / 중요 이슈 중 여러 개를 선택하거나 직접 요청해 주세요.
사용자: 내가 할 일과 중요 이슈. 방에서 제 닉네임은 ‘담당자A’예요.

Codex: 지정한 방과 기간을 확인한 뒤, 근거가 있는 할 일과 중요 이슈를 정리합니다.
```

세 가지를 처음부터 알려주면 같은 질문을 반복하지 않습니다. 원하는 결과를 말하지 않은 경우에는 반드시 묻고 답을 받은 뒤 조회합니다.

## 조회 후 할 일

| 선택 | 결과 |
|---|---|
| 전체 요약 | 주제별 주요 대화, 결정, 진행 상태, 남은 질문 |
| 내가 할 일 | 본인에게 배정되었거나 본인이 하겠다고 한 일, 기한, 근거 |
| 중요 이슈 | 마감 변경, 미해결 질문, 충돌하는 안내, 확인이 필요한 정황 |
| 직접 요청 | 예: 일정만 추출, 결정 사항만 정리, 질문과 답변 묶기 |

‘내가 할 일’을 선택하면 해당 방의 본인 이름·닉네임을 확인합니다. 방의 모든 요청을 사용자 업무로 배정하지 않습니다. 일반 채팅방의 사담도 전체 요약에 필요한 맥락이면 포함하며, To Do는 실제 실행 약속이 있을 때 만듭니다.

## 설치

Codex에서 다음과 같이 요청하세요.

```text
$skill-installer로 https://github.com/rod0826/kakaotalk-codex-skill 저장소의
skills/kakaotalk-review 스킬을 설치해줘.
```

수동 설치를 원하면 저장소를 내려받아 `skills/kakaotalk-review` 폴더를 사용자 스킬 폴더 `~/.agents/skills/` 아래에 복사합니다. Windows에서는 사용자 홈의 `.agents/skills/`를 사용합니다. 기존 같은 이름의 스킬이 있다면 덮어쓰기 전에 내용을 확인하세요. 설치 후 목록에 나타나지 않으면 Codex를 다시 시작합니다.

로컬 스킬 탐색 경로와 설치 방식은 [OpenAI 공식 안내](https://learn.chatgpt.com/docs/build-skills)를 참고하세요. 이 저장소는 직접 설치하는 스킬이며, 공식 플러그인 디렉터리 등록을 뜻하지 않습니다.

## 실행 예시

```text
$kakaotalk-review
일반 채팅방 ‘새봄 프로젝트’를 2026-09-07~2026-09-08 기간으로 조회해줘.
조회 후에는 전체 요약과 중요 이슈를 정리해줘.
```

```text
$kakaotalk-review
이미 참여 중인 오픈채팅방 ‘가상 행사 준비모임’의 어제 대화를 조회해줘.
조회 후 할 일은 ‘내가 할 일’이야. 내 닉네임은 ‘운영A’야.
```

이 문서와 예시 문서의 채팅방·인물·날짜·대화는 사용법 설명을 위해 새로 만든 가상 사례입니다. 실제 테스트 대화를 이름만 바꿔 전재한 예시가 아닙니다.

## 준비

- Computer Use를 사용할 수 있는 Codex 환경과 로그인된 카카오톡 데스크톱 앱이 필요합니다. 이 스킬을 설치하는 것만으로 컴퓨터 사용 기능이나 앱 권한이 추가되지는 않습니다.
- macOS에서는 **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**, **화면 기록** 권한을 Computer Use가 요청한 구성요소에 허용합니다. VoiceOver를 켜는 것과는 별개입니다.
- 카카오톡 내부에 스크린리더·접근성 지원 옵션이 있으면 첫 실행 때 확인하고 지원 시 활성화합니다. 구체적인 메뉴 경로는 버전별 실제 화면을 따릅니다.
- Windows에서는 제공되는 Computer Use 설정 안내를 따르고, 작업 중 카카오톡 창이 보이게 유지합니다.

자세한 경로와 제한은 [접근성 준비](skills/kakaotalk-review/references/accessibility.md), [OpenAI Computer Use 안내](https://learn.chatgpt.com/docs/computer-use)를 참고하세요.

## 데이터와 동작 범위

카카오톡은 사용자의 컴퓨터에서 열지만, 읽은 화면과 텍스트는 Codex가 처리합니다. 완전한 로컬 전용 분석 도구는 아닙니다.

분석은 지정한 방과 기간을 대상으로 합니다. 메시지 발송, 오픈채팅 신규 참여, 초대 링크 전달, 일정 등록은 기본 실행에 포함되지 않습니다. 채팅방을 열면 읽음 상태가 바뀔 수 있습니다. 사진 원본을 저장하려면 사용자가 로컬 저장을 요청한 범위에서 처리합니다.

실제 대화, 분석 결과, 첨부 파일, 세션 캡처를 이 저장소나 GitHub 이슈에 올리지 마세요. 오류를 제보할 때는 가상 메시지로 재현하고 개인정보를 제거해 주세요. 공개 저장소에는 실사용 대화 및 화면을 포함하지 않았습니다.

## 현재 확인 범위

| 환경 | 확인한 내용 | 제한 |
|---|---|---|
| macOS · 일반 채팅방 | 날짜·발신자·본문 읽기, 날짜 구분선 확인, 화면의 이미지·이모티콘 확인, 전체 요약 | 오늘의 대화는 조회 시점까지만 포함 |
| macOS · 오픈채팅방 | 본문·날짜 읽기, 별도 댓글 읽기, 일부 이미지 확대, 실행 계획과 완료 보고 구분 | 일부 이미지·댓글의 완전 수집은 확인하지 못함 |
| Windows | 운영 절차 문서화 | 이 저장소의 실사용 검증에서는 미확인 |

실제 속도는 대화량·스크롤·댓글 로딩·사진·권한 상태에 따라 달라집니다. 로컬 Jev류 모델은 기본 의존성이 아닙니다. 먼저 화면 수집이 안정적인지 확인하고, 추가 분류기가 필요한지는 실제 작업량을 기준으로 판단합니다.

[가상 사용 예시](docs/examples.md) · [검증 범위](docs/verification.md) · [스킬 원문](skills/kakaotalk-review/SKILL.md)

로컬 판단 모델(Laya)과 클라우드 판단 모델(Jev API)을 이용한 1차 분류도 검토·시험했습니다. 다만 현재는 Codex가 Computer Use로 수집하는 과정에서 이미 원문을 읽으므로 별도 분류를 추가하면 처리가 중복됩니다. 전체 작업의 시간·비용 절감이 확인되지 않아 배포 기능에서 제외하고, Codex가 직접 판단하는 구성을 유지합니다.
